# worst-pizza-topping-01

A one-line entry for "The Worst Pizza Topping": a pizza pitched with live goldfish in warm cheese, flopping and making eye contact until you apologize to the slice. `main.ts` writes the line from `line.ts` to `entry.txt` in the output directory, with no trailing newline.
